# 이 대화를 KAIROS에 보관

사용자가 보관을 요청했을 때만 실행한다. 다음 명령이 이 프로젝트의 가장 최근 롤아웃(지금 이 세션)에서 **아직 보내지 않은 턴만** 보내고 세션을 마감한다.

```bash
python3 "{KAIROS_CLIENT}" --client codex replay --project "$PWD"
```

보낸 턴 수를 한 줄로 알린다. 보낼 턴이 없었으면 이미 보관되어 있다고 말한다. 실패 줄이 있으면 그 사유를 그대로 전한다.

보관에는 사람이 친 프롬프트와 어시스턴트의 답변 텍스트만 들어간다. 도구 호출·도구 결과·터미널 입출력은 들어가지 않는다. 지금 이 턴은 롤아웃에 아직 다 쓰이지 않았을 수 있으며, 다음 보관 때 이어서 들어간다.
